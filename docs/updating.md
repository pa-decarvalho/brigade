# Updating

```sh
mise run brigade:update
```

This runs `copier update` with the answers in `.mise/brigade-copier-answers.yml` and applies the latest brigade release: new tool versions, new tasks, CI changes.
Commit your work first: Copier needs a clean git tree, and shows conflicts as inline markers.

brigade releases are tagged `X.Y.Z`. Tool versions are bumped by Renovate in brigade, so a project gets them through a release and `brigade:update`.

## What is overwritten

Files generated by brigade belong to brigade: local edits show up as conflicts on update.

Files you add are yours: brigade never touches them, such as your own workflows or `.gitlab/ci/*.yml` files.

See [CI platforms](ci.md). For your own tasks, see [Custom tasks](custom-tasks.md).
